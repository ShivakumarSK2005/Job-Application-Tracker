// My Understanding
// pom.xml -> is for holding dependencies like node modules
// maven is like npm + some more functionality
// spring is like nodejs + express
// DTO is hadeling the data, what user need to request and what response need to sent back to user
//

// Don't say: pom.xml is for holding dependencies like node_modules
// Because node_modules actually contains the downloaded packages, whereas pom.xml declares which dependencies your project needs.

// Similar relationship:

// Node.js:
// package.json  → declares dependencies
// node_modules/ → downloaded dependencies

// Java/Maven:
// pom.xml       → declares dependencies
// ~/.m2/        → downloaded Maven dependencies

// And for DTO:

// Client
   ↓ request
// Request DTO
   ↓
// Service
   ↓
// Response DTO
   ↓
// Client


// GPT 
// pom.xml → defines/manages the dependencies and build configuration of a Java/Maven project
//             (similar to package.json in Node.js)

// Maven → similar to npm + build/project management functionality
//         It downloads dependencies, compiles, tests, packages, etc.

// Spring → framework for building Java applications
//          Spring Boot + Spring MVC is roughly comparable to Node.js + Express

// DTO → defines the data shape transferred between the client and server
//       Controls what data the user can send in a request
//       Controls what data the server sends back in a response

Pagination Happens After Sorting
Pagination is Used because : let assume we have 500 jobs we dont want all of them, So we use a page to retrive only some of them by giving the page number and size of each page in query.

let assume we have 500 jobs we give quey page = 0 and size = 100
the jobs are divided into 5 pages each of them with 100 pages(pag1 0, page 1, ...., page 4), so for subsequent queries with page = 1, size = 100, next 100 jobs will be retrived.

// JWT 
Header
  → HS384 algorithm

Payload
  → sub = shiva@gmail.com
  → iat = issued-at time
  → exp = expiration time

Signature
  → verifies that the token wasn't modified

JWT = EncodedHeader.EncodedPayload.Signature

Header  → Base64URL encoded → can be decoded
Payload → Base64URL encoded → can be decoded

Signature = HMAC-SHA256(
    EncodedHeader + "." + EncodedPayload,
    secret_key
)

Signature → cryptographic hash/MAC → cannot be reversed to get the secret key

//
Encoding     → can be decoded
Encryption   → can be decrypted with a key
Hashing      → cannot be reversed

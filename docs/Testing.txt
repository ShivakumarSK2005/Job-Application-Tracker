Before we write the test, there's one important issue:

Your JobService currently depends on:

JobRepository
UserRepository
MongoTemplate
SecurityContextHolder

So testing it directly requires mocking the authenticated user as well.
That's actually useful because you'll learn how Spring Security interacts with service tests.
We'll start with a create-job test.

What the test should verify

When a logged-in user creates:

{
  "company": "Google",
  "role": "Software Engineer",
  "location": "Bangalore",
  "status": "APPLIED",
  "appliedDate": "2026-09-20"
}

the service should:

JWT user
   ↓
getCurrentUser()
   ↓
user ID = 123
   ↓
job.userId = 123
   ↓
repository.save(job)

The test should verify that the userId is automatically assigned.
Important: the client never sends userId.
That's one of the security properties we've built into this project.
